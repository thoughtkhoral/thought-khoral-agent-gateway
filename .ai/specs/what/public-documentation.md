## Purpose

Help users understand the planned external-agent boundary while preventing the
specification-only repository from being mistaken for an implemented gateway.

## Acceptance criteria

- The README clearly states specification-only status and the absence of runtime
  installation commands.
- The README links the planned responsibility, compatibility boundary, local
  specifications, and root project map.
- Any future implementation adds approved contracts, security boundaries, and
  verification instructions before publishing runtime documentation.
