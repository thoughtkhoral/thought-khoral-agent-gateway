# Agent gateway public documentation

## Status

Approved

## Purpose

Help users run and verify the local reference-agent foundation without
mistaking it for remote-agent admission or production deployment.

## Acceptance criteria

- The README states that only the deterministic local reference agent is
  runnable through the sibling platform stack and links its verification path.
- The README links the planned responsibility, compatibility boundary, local
  specifications, and root project map.
- The README identifies deferred remote admission, MCP, model/tool execution,
  and production trust controls before publishing broader runtime instructions.
